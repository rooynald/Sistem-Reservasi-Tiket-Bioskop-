## Deskripsi Sistem
Sistem Reservasi Tiket Bioskop merupakan aplikasi berbasis Command Line Interface (CLI) untuk membantu admin mengelola pemesanan tiket film. Data reservasi disimpan sementara dalam list of dictionary Python (Array of Struct).

## Cara Menjalankan
1. Pastikan Python 3.8 atau lebih baru telah terpasang.
2. Buka terminal pada folder project.
3. Jalankan perintah `python main.py`.

## Fitur Tahap 1
- Tambah reservasi beserta validasi kode, nama, jenis, tanggal, jam, jumlah tiket, dan kursi.
- Tampilkan seluruh reservasi.
- Cari berdasarkan kode (exact match) atau nama (partial match).
- Perbarui status menjadi Selesai atau Dibatalkan.
- Filter data berdasarkan status.
- Hapus reservasi dengan konfirmasi.

## Pembagian Tugas (rancangan)
- Anggota 1: perancangan struktur data, fitur tambah reservasi, tampilkan data, dan validasi input.
- Anggota 2: fitur pencarian, update status, filter, hapus, pengujian, dan dokumentasi.
Sesuaikan pembagian ini dengan pekerjaan dan commit yang benar-benar dilakukan.
